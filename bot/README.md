# 카드뉴스 자동 게시 (서버)

집 PC가 꺼져 있어도 깃허브가 대신 인스타그램에 올려주는 장치입니다.

- **매일 아침 7:40(한국시간)** 에 `output/` 안의 대기 배치 **한 편**을 게시합니다.
- 대기열이 비어 있으면 아무 일도 하지 않습니다.
- 게시 전에 인스타 토큰을 자동으로 연장합니다(만료 방지).

## 폴더
- `pipeline/` — 게시 스크립트 (내용 생성은 집 PC에서 합니다)
- `output/<날짜>/` — 올릴 배치. 카드 7장 + reel.mp4 + caption.txt
- `data/posted.json` — 이미 올린 배치 기록 (중복 게시 방지)

## 새 배치를 올리려면
집 PC에서 만든 `output/<날짜>` 폴더를 이 아래에 넣고 커밋하면 됩니다.

## 필요한 시크릿
저장소 Settings → Secrets and variables → Actions

| 이름 | 설명 |
|---|---|
| `IG_USER_ID` | 인스타 계정 번호 |
| `IG_ACCESS_TOKEN` | 인스타 액세스 토큰 |
| `GH_CONTENT_TOKEN` | 이미지·영상을 이 저장소에 올릴 토큰 |
| `GH_SECRETS_PAT` | (선택) 토큰 자동 연장용. 없으면 60일마다 수동 교체 |
