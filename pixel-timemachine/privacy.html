Privacy Policy

Pixel Time Machine Uploader is a private tool used only by the owner of the Pixel Time Machine channel. Last updated: 21 November 2026.

What it does

The tool uploads videos made by the channel owner to the owner's own YouTube channel and Instagram account, using the official YouTube Data API and Instagram API.

Data it uses

  • It uses an access token granted by the channel owner, stored only on the owner's own computer.
  • It does not collect, store, sell or share any information about viewers or any other users.
  • It does not use Google user data for advertising or for any purpose other than uploading the owner's videos.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
